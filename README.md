### 🚀 Principais Projetos em Destaque

**Projetos autorais**

- 🚗 **[AstaCar](https://github.com/devraphaeldiniz/rentalcar)** ([demo no ar](https://rentalcar-eight.vercel.app)): locadora de carros com Next.js 15, TypeScript, Hasura e PostgreSQL. Checkout com Mercado Pago em modo de teste, proteção contra overbooking via `EXCLUDE USING gist`, painel admin com funil de conversão, 105 testes de unidade e testes E2E.
- 📋 **[Gestão de Compras e Cotações](https://github.com/devraphaeldiniz/gestao-compras-cotacoes)** ([demo no ar](https://compras-cotacoes.onrender.com)): API REST em Java 21 e Spring Boot 4 que automatiza a compra de reposição. O estoque mínimo abre a cotação, os fornecedores são convidados por e-mail e o aprovador decide entre 3+ propostas por menor preço ou pontuação ponderada. JWT com perfis (quem cota não decide), recebimento parcial com custo médio, 88 testes com PostgreSQL real (Testcontainers), 90% de cobertura e E2E com Playwright.
- 🛍️ **[Nexus Shop](https://github.com/devraphaeldiniz/nexus-shop)** ([demo no ar](https://nexus-shop-raphaeldiniz.vercel.app)): e-commerce com API REST em Fastify, Prisma, PostgreSQL e Redis, e front em Next.js. JWT em cookie httpOnly com refresh rotativo e webhooks assinados de Pix e cartão.
- 💬 **[WhatsApp Disparador](https://github.com/devraphaeldiniz/whatsapp-disparador)**: disparo de mensagens em Node.js e Express com fila em SQLite e worker.
- 🤖 **[Gerador de Planos de Aula com IA](https://github.com/devraphaeldiniz/plano-aula-ia)**: aplicação integrada à API do Google Gemini com validação de schema via Zod.
- 🌐 **[Portfólio](https://www.devraphaeldiniz.com.br/)**: site pessoal em Next.js 16, React 19, TypeScript e Tailwind CSS.

**Desafios técnicos de vagas**

- 🔒 **[E-commerce Backend (Supabase)](https://github.com/devraphaeldiniz/ecommerce-supabase)**: modelagem em PostgreSQL com Row Level Security nas 8 tabelas, 4 papéis de acesso, triggers de auditoria e 27 testes automatizados.
- 📦 **[Jitterbit Orders API](https://github.com/devraphaeldiniz/jitterbit-orders-api)**: API REST em Node.js e Express para pedidos, com JWT, validação com Zod, Swagger e rate limiting.

**Projetos de estudo em outras stacks**

- ⚡ **[Fintech Core Engine](https://github.com/devraphaeldiniz/fintech-core-engine)**: transferências em Go com partidas dobradas, locks com Redis e particionamento no PostgreSQL.

| :--- | :--- |
